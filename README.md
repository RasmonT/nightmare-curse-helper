# Nightmare Curse Helper

A reference card for the curse at The Nightmare and Phosani's Nightmare. While you are cursed,
each protection prayer button turns on a different protection. This plugin shows that table as
prayer icons in a small box next to the fight and in the sidebar, so you do not have to remember
which button is which.

The table is always the same. The plugin does not detect the curse, does not look at the boss's
attacks, does not tell you which prayer to use at any moment and does not time anything.

## While cursed

| You click | You get |
| --- | --- |
| Protect from Melee | Protect from Magic |
| Protect from Magic | Protect from Missiles |
| Protect from Missiles | Protect from Melee |

In the box and the sidebar each row is drawn as two prayer icons with an arrow: the prayer you
click on the left, the protection you get on the right.

## The box and the sidebar

Both appear in the Nightmare's arena by default. Turn off *Box only at the Nightmare* to keep the
box on screen everywhere, for example to learn the table before a trip, and *Panel only at the
Nightmare* to keep the sidebar button there all the time.

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| Show box | On | The box with the table |
| Box only at the Nightmare | On | Off: the box stays on screen everywhere |
| Side panel | On | The table and a short explanation in the sidebar |
| Panel only at the Nightmare | On | Off: the sidebar button stays there everywhere |

## Data

The plugin stores nothing and makes no network requests.
